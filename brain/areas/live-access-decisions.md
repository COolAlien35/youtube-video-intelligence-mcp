# Deciding whether a demonstration can use live data

Use synthetic provider responses for the Phase 1 demo. A successful demo can prove that an approved proposal reaches the fixture provider. It cannot supply written platform clearance. The feature owner must match the proposed remote interface and each derived output to the evidence in the compliance ledger before enabling live access. User confirmation remains a separate requirement for each playlist write.
