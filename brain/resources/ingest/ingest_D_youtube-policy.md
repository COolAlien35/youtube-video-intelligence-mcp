# YouTube policy gates for the remote MCP service

## Source

[YouTube API Services Developer Policies](https://developers.google.com/youtube/terms/developer-policies), especially III.C, III.E and III.I. Project SRS v1.0 candidate §2.3 and Appendix C.

## Ingested by / date

Person D · 2026-11-22 · AI-assisted draft for review.

## Summary

The project proposes remote tools for discovery, analysis and approved writes.
YouTube’s policies govern how clients use API data and present actions.
The SRS translates those obligations into project-specific release gates.
A user’s consent to a playlist does not establish permission to expose remote API functionality.
Fixture demonstrations let the team verify behavior while written determinations are pending.

## Key facts

- POL-01/02/03 group derived outputs and require evidence for the exact use case (SRS §2.3).
- POL-04/05 cover consented account-data use and the compliance record (SRS §2.3).
- POL-06 requires evidence for cross-owner aggregation. POL-07 covers presentation, links and attribution. POL-08 covers written guidance on the remote MCP interface (SRS §2.3).
- Users retain control over data published through client write operations (Developer Policies III.C.3).

## Relevance

POL-01 through POL-08 govern enablement. FR-5 and Appendix C bind a write to explicit confirmation.
